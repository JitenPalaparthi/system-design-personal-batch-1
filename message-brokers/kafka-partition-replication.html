Key idea

Topic orders
 ├─ P0 → B1 Leader → B2/B3 Followers
 ├─ P1 → B2 Leader → B3/B1 Followers
 └─ P2 → B3 Leader → B1/B2 Followers

Topic payments
 ├─ P0 → B2 Leader → B1/B3 Followers
 └─ P1 → B3 Leader → B2/B1 Followers

Partitioning provides scalability/parallelism. Replication provides fault tolerance. Each partition—not each topic—has its own leader.
